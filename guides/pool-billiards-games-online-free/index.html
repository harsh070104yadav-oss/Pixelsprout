Tips

Line up the cue ball, the object ball and the pocket before you add power. A softer shot is easier to control when the angle is thin. On a snooker or carom table, think about where the cue ball will stop, not only whether the current ball drops. If you are new to a ruleset, use a practice mode first when the game offers one.
